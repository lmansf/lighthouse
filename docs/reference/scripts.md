# Helper script guide

| Script | What it does | Why it helps |
| --- | --- | --- |
| `brand-screens.mjs` | Takes and puts together product pictures. | The pictures can be made the same way every time. |
| `build-ui-static.mjs` | Packs the screen files for the app. | The computer and phone versions get the same screen. |
| `check-contrast.mjs` | Checks that words are easy to see on their background. | More people can read the app. |
| `check-stamps.mjs` | Checks important version labels. | It stops mixed-up version numbers. |
| `e2e-sidebar-flyout.mjs` | Tries the side bar and pop-out parts like a person would. | It checks that pieces work together. |
| `egress-proof.mjs` | Checks when the app is allowed to talk to the internet. | It helps protect privacy promises. |
| `fetch-local-model.mjs` | Gets checked helper files for reading and answering. | The app knows it got the right files. |
| `gen-glyphs.mjs` | Makes the app's little picture symbols. | The symbols stay matching. |
| `gen-icons.mjs` | Makes app icons for different computers. | The app looks like itself everywhere. |
| `generate-reference.mjs` | Makes the big lists of code jobs in this guide. | The lists do not get old when code changes. |
| `openspec-validate.mjs` | Checks that a written plan and the code agree. | It helps stop surprises later. |
